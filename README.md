# 5-Menit Aja

Aplikasi Android sederhana yang membantu kamu memulai tugas dengan komitmen lima menit.

## Fitur

- Input satu tugas, mulai timer 5 menit
- Pause, resume, atau berhenti kapan saja
- Berhenti setelah 5 menit = berhasil
- Riwayat sesi tersimpan lokal
- Offline sepenuhnya, tanpa akun

## Tech

Kotlin · Jetpack Compose · Room · DataStore

## Build

```
./gradlew assembleDebug
```

## Lisensi

Hak cipta dilindungi.
